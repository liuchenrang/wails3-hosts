# HostsManager

HostsManager 是一款功能强大且易于使用的 hosts 文件管理工具，旨在帮助用户轻松管理本地 hosts 文件，快速切换不同的 hosts 配置，解决域名访问问题。

## 功能特性

- **简洁易用的界面** - 直观的图形界面，轻松管理 hosts 记录
- **快速切换** - 一键切换不同的 hosts 配置场景
- **多平台支持** - 支持 Windows、macOS、Linux 系统
- **导入导出** - 方便地导入和导出 hosts 配置
- **历史记录** - 保留配置历史，随时回溯
- **安全可靠** - 操作前自动备份，保障数据安全

## 使用说明

1. 下载并安装对应平台的版本
2. 启动应用程序
3. 添加或导入 hosts 记录
4. 选择需要启用的配置
5. 保存并生效
