Hosts Manager

Powerful features, simple to use

Built for developers — say goodbye to the hassle of managing hosts files

Group Management

Create hosts groups per project or environment. Enable or disable an entire group with one click — switching between dev, staging, and prod has never been easier.

Entry Management

Visually add, edit, and delete hosts entries. Fill in IP, hostname, and comment — no more typing commands in the terminal.

Keyboard Shortcuts

Cmd+S on Mac or Ctrl+S on Windows to apply changes instantly — keep your flow going.

Version History

Every change is automatically saved. Made a mistake? Roll back to any previous version instantly — your hosts file is always recoverable.

Multi-language Support

English, Chinese, and Japanese built in. The UI automatically matches your system language — great for international dev teams.

Light & Dark Theme

Toggle between light and dark mode. Late-night coding sessions are easy on the eyes.
